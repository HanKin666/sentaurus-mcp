# alpha.3 更新说明

**状态：预发布测试版。** 标签为 `v0.1.0-alpha.3`，Python 包版本为 `0.1.0a3`。

## 为什么仍是 alpha

alpha.3 是软件预发布候选。当前验证覆盖一个 Windows 本地 MCP/Worker 环境和一次 Linux Sentaurus 原生工具执行路径；该真实执行经操作者单独配置的 SSH 工具适配器完成，适配器不包含在发布包中。Linux 端直接部署 MCP 尚未验证，故障恢复覆盖也有限，尚无跨平台、跨依赖版本的兼容矩阵。

因此，这次预发布的理由是软件部署和运行覆盖仍窄。alpha 是软件成熟度标签，不对任何科学结论作判断；随附的一次小型冒烟测试不构成器件研究结果、模型校准或物理验收。

## 本次更新

- 为运行状态增加新鲜观测与失败诊断信息，并支持检查预期输出文件。
- 支持将一个或多个已结束的实验打包为 ZIP，并在清单中记录文件校验信息。
- 增加原生工程只读索引、按字段名读取 ASCII PLT 数据及图像来源记录。

功能对应本版本的发行包和源码提交。

## 验证摘要

- 原有回归套件：33 passed、1 skipped、0 failed。
- 独立合成客户端场景：另有 6 项通过，不与上述套件计数合并。
- 真实软件冒烟：Sentaurus T-2022.03 原生工具完成一次 10 × 1 µm 硅电阻单偏压流程，结构、网格和电流摘要见[验证记录](../VALIDATION.md)。

测试环境、验证边界和冒烟测试性质详见[验证记录](../VALIDATION.md)。仅提供[通用样例输入](../examples/smoke/README.md)，实际连接配置、原生输出、日志和运行记录保留在私有验证环境，不随发布包提供。
