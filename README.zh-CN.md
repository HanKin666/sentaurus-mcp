# Sentaurus MCP

这是独立的、可供不同 MCP 客户端使用的 Sentaurus 批处理工具。**不包含也不依赖作者的私人工作台、科研结构、实验记录或服务器账号。**

架构：LLM 客户端 → MCP → SQLite 实验服务 → 独立 Worker → SDE / SDevice / SVisual。

## 使用

1. 用 Python 3.10+ 建立虚拟环境，执行 `python -m pip install -e '.[test]'`。
2. 复制 `examples/config.example.json` 到私有位置，配置数据目录、真实可执行文件和最大并行数。
3. 设置 `SENTAURUS_MCP_CONFIG` 指向该配置。
4. **独立启动 `sentaurus-worker`**，由服务器服务管理器或独立终端管理。不能把它作为 MCP 客户端的子进程启动。
5. 给 MCP 客户端配置 `sentaurus-mcp` 可执行文件和相同配置路径。
6. 默认只读；操作员设置 `SENTAURUS_ENABLE_ACTIONS=1` 后允许准备和提交实验。

对于 Linux 上的 Sentaurus，在 Linux 上运行 Worker 和 MCP。Windows 客户端可以通过其配置的 SSH STDIO 通道访问。真实软件版本和命令参数需要在自己的环境核验。

## 已实现

- 创建分项目的独立实验目录，保存文本输入及 SHA-256 指纹。
- 持久化实验索引，跨客户端读取同一状态。
- 异步入队、Worker 启动、并行数量限制、防重复提交。
- 按阶段记录日志、退出码、墙钟耗时、进程编号。
- 日志增量读取、原生结果文件索引。
- MCP 退出不会通过父子进程关系结束独立 Worker 的任务。
